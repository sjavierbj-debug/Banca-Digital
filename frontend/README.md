# Banca Digital – Frontend (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173
```
Requiere el backend en http://localhost:8080 (cambiar en `.env`, variable `VITE_API_URL`).

Pantallas: ingreso/registro, resumen (saldo y movimientos), depósito, retiro (PIN + billetes entregados), mis datos y seguridad (clave y PIN).
